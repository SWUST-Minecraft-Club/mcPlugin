# Wallet ChangeLog（测试版）

版本命名与产物见 `./docs/dev/版本与产物规范.md`。
格式：`[新版本] 时间` 或 `[上一版本 -> 新版本] 时间`，下面列本次改动（新增 / 修复 / 调整）。

---

[Beta_0_1_0] 2026.10.20 11:00:00
1.新增：主菜单钱包功能（绿宝石）—— 普通玩家悬停逐行显示本服启用货币的余额、点击打开流水页；
   管理员左键打开「玩家货币」页、右键打开「货币种类」页；本服没有启用货币时图标显示「暂无货币」
2.新增：流水页（纸图标）—— 第 1~5 行按时间倒序显示流水（类型/金额/币种/时间/余额/备注/业务号），
   第 6 行 47 上一页、49 返回主菜单、51 下一页；货币种类页用黄绿/红色羊毛表示本服是否启用；
   玩家货币页列出本服有在线时长记录的玩家（读 `plugins/YudreamMinecraftServer/playtime.yml`）及余额
3.新增：`WalletApi` / `WalletService` 给后续插件依赖 —— `assets / balance / credit / debit / transactions`，
   全部返回 `CompletableFuture`；所有加减货币直接调用官网接口（官网流水即上报结果），本地不保存余额，
   只提供 `cachedAssets / cachedBalance` 供渲染路径读取
4.调整：货币与流水全部走官网 `/api/plugins/yudream-wallet`；兼容平台响应信封（`data`）与
   长整型/BigDecimal 的字符串序列化；流水查询先用 `game/balance` 解析站内 `userId` 再查管理端流水
5.说明：依赖 MainMenu 的按查看者渲染与 `MainMenuApi.open(player)`（`Beta_1_1_0` / `Beta_1_2_0` 起）；
   API Key 需要 `plugin:yudream-wallet:manage` 权限；未绑定官网账号的玩家显示「未绑定网站账号」

[Beta_0_1_0 -> Beta_0_2_0] 2026.10.20 13:10:00
1.新增：管理员在「货币类型」页**点击羊毛即可在本服启用 / 停用该货币**（黄绿色 = 启用、红色 = 停用），
   切换结果写进 `plugins/Wallet/assets.yml`（优先于 config.yml 的 assets 初始列表，改 config 不会丢注释）；
   官网停用的货币点不上，会提示"官网已停用该货币"
2.修复：「返回主菜单」按钮点了没反应、只是把界面关掉 —— 改为下一 tick 重新打开主菜单；
   同时兼容旧版 MainMenu（运行期没有 `MainMenuApi.open` 时退回执行 `/cd`）
3.说明：本服启停只影响本服菜单显示与余额查询范围，不改官网资产的全局状态；每笔货币变动仍以官网流水为准

[Beta_0_2_0 -> Beta_0_2_1] 2026.10.20 14:10:00
1.修复了"停用一个币种后，流水页仍能看到该币种的流水"：流水查询以前不带币种过滤，官网返回的是
   这个玩家**所有币种**的流水。现在流水页只查本服启用的币种 —— 单币种直接让官网按 `assetCode` 过滤；
   多币种按币种分别取够所需条数后合并、本地分页（总条数按各币种 total 求和）；停用的币种不再出现
2.新增：`WalletService.transactions(..., assetCodes, ...)` 币种过滤重载（`null` = 全部币种，
   空列表 = 空页），后续插件也可以按需使用；原来的 4 参数重载行为不变（全部币种）

[Beta_0_2_1 -> Beta_0_3_0] 2026.10.22 01:31:00
1.新增管理员指令：`/walletin <玩家名> <币种编码> <数量>` 给在线玩家加币，
   `/walletout <玩家名> <币种编码> <数量>` 从在线玩家扣币；玩家名不区分大小写，且必须在线
2.权限：新增 `wallet.adjust`（默认 OP）控制两个指令；同时把菜单使用的 `wallet.admin` 正式写进
   `paper-plugin.yml`（默认 OP）
3.校验：币种必须存在于官网且 `enabled=true`；数量必须大于 0，并按资产 `scale` 校验小数位；
   操作走 Wallet `credit` / `debit` 写回官网，`businessNo` 为 `wallet-admin-in/out-<uuid>`，
   官网来源识别为 `ADMIN`，备注包含执行指令的管理员名称；成功回复变动金额和官网余额
4.说明：只影响在线玩家；官网返回失败/余额不足时原样提示，不在本地记账

[Beta_0_3_0 -> Beta_0_4_0] 2026.10.22 23:45:00
1.新增：适配 Folia 26.3 —— `paper-plugin.yml` 声明 `folia-supported: true`，编译依赖改为 Folia API
2.调整：官网异步回调、流水 / 货币类型 / 玩家货币三个界面的打开与重绘改走玩家实体调度器；
   返回主菜单、翻页、切换币种只在该玩家所属区域线程操作背包
3.调整：管理员指令的异步回复回到执行者所属区域线程发送（控制台仍直接输出）
