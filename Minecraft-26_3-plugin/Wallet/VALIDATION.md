# Wallet Beta_0_6_0 验证

## 环境

2026-10-26，独立 Folia 26.3 build 5 / Java 25 / Gradle 9.8.1，使用用户提供的 Vault 1.7.3-b0-folia、MainMenu Beta_1_7_0、Town Beta_0_7_1。所有账户、余额和官网 HTTP 均为本机夹具；未访问真实 YuDream 官网钱包，未替用户执行真实迁入。

## 自动测试

`./gradlew :MainMenu:build :Wallet:build`（本机使用相同版本缓存和 offline 构建）。MainMenu 7 项、Wallet 13 项 JUnit：

- 账本：UUID / 币种隔离、幂等与业务号冲突、重启恢复、一次性迁入标记、校验失败无部分入账、截断半条尾记录、完整 CRC 损坏拒绝加载、并发扣款不透支、内部业务号保护。
- 迁入：只读官网、成功只提交一次、后续 HTTP 失败整批零写入、同一网站身份不可复制给多个 UUID、返回 UUID 不一致拒绝、明确未绑定玩家报告跳过、其它接口绑定错误不得跳过。
- MainMenu：10 页模板、动作/权限/保留文件契约、头像有效格式与无效回退、长金额格式。

## 边界

- 本地模拟旧接口验证了迁入流程；真实官网 API Key 权限、生产数据分布与官网余额快照一致性仍由实际迁入前核对。
- 迁入仅限本服已知 UUID、配置启用币种；不包含从未进服的网站用户和旧官网历史流水；成功后不持续同步。
- 断电测试为尾记录截断和 CRC 损坏模拟，未声称验证所有磁盘/文件系统的真实掉电行为。
- Town 本轮核对实际 Vault 连接及适配层扣款、幂等重试、退款；Town 既有业务的完整覆盖仍以其原验证记录为准。
- 原钱包界面沿用背包；新主页资产页原生 ArcMenu。未验证任意第三方自定义皮肤 URL 和任意资源包模型。
- 字符串玩家名只查本服缓存；离线账户以 UUID 为准。Vault 标准接口仅暴露一个主币种，不支持银行。

产物哈希及本轮客户端逐项结果见 [结构化结果](../MainMenu/assets/vault-validation-results.json)。
