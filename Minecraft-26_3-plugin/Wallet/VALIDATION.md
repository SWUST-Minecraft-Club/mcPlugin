## Beta_0_7_0 双来源与交互验证（2026-10-27）

### 自动测试

Java 25 / Gradle 9.8.1 / Folia API `26.3.build.5-alpha`，离线运行 `:Wallet:build`；41 项 JUnit 全通过：配置 12、指令 2、来源路由 6、账本 10、迁入 11。

- 配置：任意本服 code、source 与官网 code 映射；非法来源、重复 code / 官网映射、官网币作为 Vault 主币种均拒绝。
- 路由：本地与官网读写分流、官网故障不改来源且本地继续、官网 set 零请求拒绝、精度与币种检查；520 条两来源流水跨后端 200 条分页合并，无重复或漏项。
- 本地 set：允许 0、同业务号幂等、业务号冲突与保留前缀、迁入写锁、并发 set/add、重开账本恢复。
- 指令：按权限和前缀提示根子命令；set 允许 0，add/take 拒绝 0，负数与科学计数法均拒绝。既有迁入隔离测试继续通过。

### 本轮边界

- 没有访问真实官网或使用真实密钥；没有执行生产迁入。官网 HTTP 行为使用与现有接口字段一致的本机夹具。
- 本轮 MainMenu 验证为其原版背包回退；ArcMenu 手机显示沿用已有版本的验证范围。
- 菜单与 Tab 为真实客户端操作；拖拽为实际事件总线验证。混合流水合并上限为前 10000 条，更早可按单币种查询。
- 本地账本格式和原有完成标记保持。配置来源切换不会自动搬钱；已迁入 GOLD 的服务器保留 gold 账本并启用官网 emerald 即可。

## Beta_0_6_2 迁入 UUID 隔离回归（2026-10-27）

- Java 25 / Gradle 9.8.1 / Folia API `26.3.build.5-alpha`，离线运行 `:Wallet:build`；Wallet 全部 25 项 JUnit 通过（配置 7、账本 7、迁入 11）。
- UUID 不一致的玩家在正常玩家之前或之后，均整人跳过；警告包含玩家名、本服 UUID、官网玩家名 / UUID / userId 和币种。跳过玩家原有本地余额与流水保持，正常玩家继续入账。
- 多币种处理中后一个币种 UUID 不一致或未绑定，丢弃该玩家前面币种的暂存数据，并释放未通过玩家的官网身份占用；不影响后续身份正确的玩家。
- 所有玩家均被跳过：余额为零、未写完成标记、本地写入恢复，可修正后重试。正常玩家成功迁入：余额与完成标记重启保留，重复命令被拒绝，跳过账户不会自动补迁。
- 后续 HTTP 失败仍整批零写入，前面的跳过警告已输出；有效玩家之间的重复官网身份和 API Key 权限错误仍中止。
- 使用发布 JAR 和 GOLD 专用配置做模拟迁入：仅查询官网 `GOLD` 并追加到本地 `gold`，UUID 不一致和未绑定账户跳过，`EMERALD` 余额不查询、不迁入，也不向官网写入。完整重开账本后余额与完成标记保留。
- 本轮没有连接真实官网、使用真实凭证或执行生产迁入；未新增真实服务端或客户端联调。账本文件格式和 Vault 桥接未改动。

## Beta_0_6_1 配置回归（2026-10-26）

- 使用发布的 `Beta_0_6_0` JAR、Folia API `26.3.build.5-alpha` 和不含真实凭证的旧版官网配置复现 JavaPlugin 加载过程：先读取文件，再通过 `setDefaults` 绑定 JAR 默认配置。旧版得到 `currencies=[]`，同一配置不绑定 defaults 时反而得到 `coin`。
- 修复前新增的 7 项配置测试有 1 项失败，失败点为旧配置继承默认节后没有默认 `coin`；修复后 Wallet 全部 20 项 JUnit 测试通过，包括原有账本与迁入测试。
- 7 项配置回归覆盖：旧配置绑定默认值、旧配置未绑定默认值、全新安装、自定义 `gold` 币种与 Vault 选择、显式禁用 `coin`、显式空币种节、官网模式保留地址/示例密钥/币种选择。测试不连接真实官网，不使用生产凭证。
- Java 25 / Gradle 9.8.1，运行 `:Wallet:build` 构建并归档 `Beta_0_6_1`；本机使用同版本缓存的 Gradle 和离线依赖。生产账本、迁入逻辑、Vault 桥接及官网实现未改动；本轮未新增真实服务器或客户端联调。

## 边界

- 本地模拟旧接口验证了迁入流程；真实官网 API Key 权限、生产数据分布与官网余额快照一致性仍由实际迁入前核对。
- 迁入仅限本服已知 UUID、配置启用币种；不包含从未进服的网站用户和旧官网历史流水；成功后不持续同步。
- 断电测试为尾记录截断和 CRC 损坏模拟，未声称验证所有磁盘/文件系统的真实掉电行为。
- Town 本轮核对实际 Vault 连接及适配层扣款、幂等重试、退款；Town 既有业务的完整覆盖仍以其原验证记录为准。
- 原钱包界面沿用背包；新主页资产页原生 ArcMenu。未验证任意第三方自定义皮肤 URL 和任意资源包模型。
- 字符串玩家名只查本服缓存；离线账户以 UUID 为准。Vault 标准接口仅暴露一个主币种，不支持银行。

产物哈希及本轮客户端逐项结果见 [结构化结果](../MainMenu/assets/vault-validation-results.json)。
