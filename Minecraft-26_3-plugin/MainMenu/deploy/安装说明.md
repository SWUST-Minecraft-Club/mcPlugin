# MainMenu + Wallet + Vault 更新包

适用 Folia / Minecraft 26.3、Java 25。插件版本与 SHA-256 见包内清单。

## 1. 更新插件和手机模板

1. 停服，备份原插件 JAR 与 MainMenu、Wallet、Town、ArcMenu 的配置和数据。
2. 将包内 `./server/plugins/` 的 JAR 放入服务端 `./plugins/`；移出同名插件旧 JAR，每个插件只保留一个版本。保留现有 ArcMenu 3.2 和其它必需依赖。
3. 将 `./templates/ArcMenu/menus/mainmenu/` 的 **10 页** YAML 复制到服务端同路径，覆盖前另存自己的改版。这一步包含头像校验变量、资产页和首页下一页按钮，单独换 JAR 不会覆盖旧 YAML。
4. 客户端按需更新 `./client/mods/` 的 MainMenuRepair；服务端不安装此 Fabric 模组。

本包包含最新 Town 与此前相关插件的留档版本。ArcMenu premium、CraftEngine、服务端核心、世界、账户数据及任何真实密钥均不在包内。Vault 为用户提供的 Folia 版本，文件哈希见清单；不需要额外安装 XConomy。

## 2. 合并经济配置

在服务端 `./plugins/Wallet/config.yml` **合并** `./config-merge/Wallet-local.yml`，保留原官网地址、API Key 和其它选项；示例不是整文件替换配置。

- `backend: local`，`test-mode.enabled: false`。
- 在 `currencies` 中填写旧官网币种的 **相同 code 和 scale**；`coin` 只是示例，不能用它替代原编码。
- `vault.currency` 选择一个配置启用的主币种；其它币种仍由 WalletApi 和原钱包界面使用。
- 确认 `./plugins/Wallet/assets.yml` 没有停用所选主币种。不要同时安装另一套 Vault 经济提供者。

在服务端 `./plugins/Town/config.yml` 合并 `./config-merge/Town-vault.yml`，即 `economy.provider: vault`，然后重启。旧 Wallet 来源待处理交易不会自动重放到新的 Vault 账本，不删除或重置旧交易记录。

控制台应出现 `Wallet 已向 Vault 注册主币种` 和 Town 的 `Vault / Wallet/<币种>`。`/cd` 的“我的资产”应显示该币种余额；新本地账户初始为零。

## 3. 只执行一次旧官网余额迁入

保留 Wallet 原 `base-url`、`api-key`，权限需要官网 `plugin:yudream-wallet:manage`。先停止旧官网钱包的消费/入账和其它仍写官网的游戏服，保持读取期间余额稳定。

由 OP 或控制台依次执行：

```text
/wallet migration-status
/wallet migrate-site
/wallet migration-status
```

- 读取本服已知玩家 UUID（离线玩家 + 本服时长台账）以及所有启用配置币种；从未在本服留下记录的网站用户不在迁入范围。
- 只读旧官网余额，校验完整后追加到本地余额；不搬历史流水、不扣除官网款、不持续同步。明确未绑定玩家会跳过并报告。
- 读取/校验失败无部分入账，未消耗成功机会；提交不确定时先检查磁盘并重启，再用状态指令核对。
- **成功标记与余额同次持久提交，重启后仍拒绝重复执行。** 状态文件为 `./plugins/Wallet/wallet-ledger.wal`；不得通过删除它重新迁入，否则也会丢失本地余额和流水。

此交付包没有访问或迁入真实官网数据。完整配置和已测边界见 `./docs/Wallet-README.md`、`./docs/Wallet-VALIDATION.md`。
