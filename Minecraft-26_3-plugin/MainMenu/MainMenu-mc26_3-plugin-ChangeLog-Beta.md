# MainMenu ChangeLog（测试版）

版本命名与产物见仓库 README 的「版本与产物命名规范」。
格式：`[新版本] 时间` 或 `[上一版本 -> 新版本] 时间`，下面列本次改动（新增 / 修复 / 调整）。

---

[Beta_0_1_0] 2026.10.17 12:54:26
1.新增主菜单界面：6×9 布局、功能区 21 格/页、翻页箭头
2.新增三种打开方式：ESC 菜单里的「主菜单」按钮、`/cd` 命令、手持时钟右键
3.新增功能插件 API（`com.example.mainmenu.api`）：物品 / 悬停文本 / 点击是否有效 / 点击行为 / 自定义位置
4.新增位置冲突处理：与固定功能位或其它插件冲突时自动归到功能区，并在悬停文本末尾追加提示
5.新增功能区排序与分页：按注册顺序填充，每页 21 个
6.新增 `/cd reload`、`/cd debug`（布局预览、功能位置、ESC 按钮状态、配置自检）

[Beta_0_1_0 -> Beta_0_2_0] 2026.10.17 13:30:10
1.新增 `order(int)`：功能区排序值，越小越靠前（默认 0 表示按注册顺序）

[Beta_0_2_0 -> Beta_0_2_1] 2026.10.17 17:51:35
1.修复了 ESC 菜单里的「主菜单」按钮点击后打不开界面
2.修复了构建在部分机器上因 Gradle 工具链 fork worker 失败而中断

[Beta_0_2_1 -> Beta_0_3_0] 2026.10.17 20:33:12
1.新增时钟右键支持对着空气触发（原先只响应方块）
2.修复了潜行时时钟右键无反应（`clock-while-sneaking` 默认改为允许）
3.删除在线时长功能（第 1 行第 5 格的“画”）及其 YuDream 接口调用

[Beta_0_3_0 -> Beta_0_3_1] 2026.10.17 20:39:44
1.修复了 ESC 按钮只有第一次能点开（adventure 的 `ClickCallback` 默认只能用一次）
2.修复了时钟右键空气打不开（手部判断过严，副手持钟时被漏掉）

[Beta_0_3_1 -> Beta_0_4_0] 2026.10.17 20:53:03
1.新增 `/cd clockair` 子命令：供客户端模组上报“手持时钟右键空气”
2.新增每人 200ms 的开界面冷却，避免同一次点击被多条路径触发时开两次
3.修复了时钟右键空气在服务端不产生交互事件的问题（改为客户端检测后上报）

[Beta_0_4_0 -> Beta_0_5_0] 2026.10.17 21:02:36
1.修复了 ESC →「主菜单」需要点两次的问题（装了模组后一步到位，不再出现中间 dialog 页）
2.修复了「主菜单」按钮文字不是默认白色（去掉之前设的 GOLD）

[Beta_0_5_0 -> Beta_0_6_0] 2026.10.18 08:55:58
1.新增 `menu.refresh-seconds`：菜单打开期间整页重绘的间隔，功能插件的动态文本靠它刷新
2.调整：把“显示当前时间”拆成独立插件 RealTime，第 1 行第 2 格改为普通位置（先到先得）
3.调整：时钟右键触发材质从 `menu.clock.material` 移到 `menu.open.clock-material`
